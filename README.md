## Technical Specifications

- **Framework**: Next.js 16 (App Router, Turbopack)
- **Language**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS v4 + Custom Design Tokens (`#04070D`, `#4F8CFF`, `#9F5CFF`)
- **Animations**: Framer Motion (useScroll, useSpring, useMotionValue, AnimatePresence)
- **3D Graphics**: Three.js (Isolated strictly to Hero)
- **Icons**: Lucide React
- **Accessibility**: ARIA dialog semantics, keyboard navigation, `@media (prefers-reduced-motion: reduce)` support
